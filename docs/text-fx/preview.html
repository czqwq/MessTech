关于这套特效

设计稿与落地说明见同目录 design.md
  • 一个效果 = 一个 fragment shader。公共部分（position() / coverage() / outline() / hash() / noise() / palette / time）就是模组里的 common.glsl，每个效果各是一个 <id>.frag.glsl。
  • 所有距离以字高 h 为单位（h = textSize.y），所以同一效果在任何字号、任何 GUI 缩放下比例不变；换字体的字形遮罩只影响 coverage()，不影响动效。
  • 八个效果互不重复：解码头、视界、磁力线、光刃、密文解码、墨染、声纹、落花各是一套独立机制。
  • 预览说明：字形遮罩是整行文字光栅（系统字体），不是 Minecraft 像素字体；阴影、背景只是预览近似，游戏内由渲染管线统一绘制。
